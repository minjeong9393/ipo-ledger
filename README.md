# 공모주 가계부

공모주 청약·매도 수익을 적는 1인용 가계부입니다. 광고·추적·외부 CDN 없이 화면 하나(HTML)로 동작하고,
기록은 이 기기의 브라우저(localStorage)에만 저장됩니다.

## 쓰는 법

1. 홈 화면에 추가(설치)하면 앱처럼 열리고, 한 번 열어 두면 오프라인에서도 열립니다.
2. `+ 기록` → **간편 입력**이면 최종이익 금액만, **자동 계산**이면 공모가·주수·매도가·수수료를 넣으면
   매수금액·세전차익·비용합계·최종이익·수익률이 바로 계산됩니다.
3. 상장 전 종목은 **상장 대기**로 저장하고, 매도한 날 `매도 완료 입력`을 누르면 실현이익에 들어갑니다.
4. `⋮` → JSON 백업 / JSON 불러오기 / 엑셀(CSV) 내보내기.

## 화면

- **내역**: 월별로 묶인 기록과 월 합계. 탭하면 수정, 대기 종목은 1탭으로 매도 완료 입력.
- **월별·통계**: 연도별 12개월 실현이익, 연 누적, 증권사별 합계, 수익/손실/본전과 승률, 수수료·세금 합계.

## 계산식

```
매수금액 = 공모가 × 주수
매도금액 = 매도가 × 주수 (또는 총 매도금액)
세전차익 = 매도금액 − 매수금액
비용합계 = 청약 수수료 + 매도 수수료·세금(자동 0.2% 또는 직접 입력)
최종이익 = 세전차익 − 비용합계
수익률   = 최종이익 ÷ (매수금액 + 청약 수수료) × 100
```

## 파일

- `index.html` — 로컬 미리보기용 단일 파일(샘플 기록 포함, `python3 build.py` 로 생성)
- `src/` — `shell.html`, `styles.css`, `app.js` 원본
- `deploy/` — 공개 배포본 빌드(`build_deploy.py`), 아이콘 생성(`make_icons.py`), 배포본 테스트
- `site/` — 실제 배포본(샘플 기록 없음, PWA 매니페스트·서비스워커 포함)
- `test/` — jsdom 동작 테스트, Playwright 화면 검증

## 개인정보

배포본 `site/index.html` 은 빈 시드로 만들어져 기록이 들어 있지 않습니다. 기록은 서버로 보내지 않습니다.
